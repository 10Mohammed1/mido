﻿================================================================================
  Mido · ابدأ من هنا  (ويندوز / RDP)
================================================================================

  اختر طريقة واحدة فقط — مرتبة من الأسهل:

    الطريقة 0) سطر واحد يُلصق في PowerShell (لا تنزيل ملفات ولا مسارات)
    الطريقة أ) ملف واحد            →  Mido-OneClick.ps1
    الطريقة ب) المجلد كامل         →  Mido-RDP-Install.ps1  (بدون GitHub إطلاقًا)


================================================================================
  الطريقة 0) الأسهل: انسخ السطر التالي والصقه في PowerShell واضغط Enter
             (استبدل التوكن بتوكن GitHub بصلاحية قراءة المستودع)
================================================================================

  سطر واحد جاهز للصق:

  $ErrorActionPreference='Stop'; [Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12; $s=Read-Host 'GitHub token' -AsSecureString; $t=[System.Net.NetworkCredential]::new('',$s).Password; $h=@{Authorization="token $t";'User-Agent'='Mido'}; $p="$env:TEMP\Mido-OneClick.ps1"; Invoke-WebRequest 'https://raw.githubusercontent.com/10Mohammed1/mido/main/Mido-OneClick.ps1' -Headers $h -OutFile $p -UseBasicParsing; $env:MIDO_GITHUB_TOKEN=$t; powershell -NoProfile -ExecutionPolicy Bypass -File $p; Remove-Item Env:\MIDO_GITHUB_TOKEN -ErrorAction SilentlyContinue

  أو نفس الشيء مكتوبًا على أسطر (يمكن لصق الأسطر معًا):

  $ErrorActionPreference='Stop'
  [Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12
  $s=Read-Host 'GitHub token (لن يظهر)' -AsSecureString
  $t=[System.Net.NetworkCredential]::new('',$s).Password
  $h=@{Authorization="token $t"; 'User-Agent'='Mido'}
  $p="$env:TEMP\Mido-OneClick.ps1"
  Invoke-WebRequest 'https://raw.githubusercontent.com/10Mohammed1/mido/main/Mido-OneClick.ps1' -Headers $h -OutFile $p -UseBasicParsing
  $env:MIDO_GITHUB_TOKEN=$t
  powershell -NoProfile -ExecutionPolicy Bypass -File $p
  Remove-Item Env:\MIDO_GITHUB_TOKEN -ErrorAction SilentlyContinue

  هذا السطر: يسألك عن التوكن مرة واحدة → ينزّل المثبّت → يثبّت كل شيء → يسألك
  بيانات تيليجرام → يفحص المشروع. (لأن المستودع خاص، التوكن ضروري للتنزيل.)


================================================================================
  الطريقة أ) ملف واحد: نزّل Mido-OneClick.ps1 إلى السيرفر ثم شغّله
================================================================================

    powershell -ExecutionPolicy Bypass -File .\Mido-OneClick.ps1

  ملاحظة مهمة: التنزيل من المتصفح يذهب عادةً إلى مجلد Downloads، لذلك إما:

    cd $env:USERPROFILE\Downloads
    powershell -ExecutionPolicy Bypass -File .\Mido-OneClick.ps1

  أو اعرف مكان الملف أولًا:

    Get-ChildItem $env:USERPROFILE -Recurse -Filter 'Mido-*.ps1' -ErrorAction SilentlyContinue | Select-Object -First 5 FullName


================================================================================
  الطريقة ب) المجلد كامل (بدون أي توكن أو اتصال بـ GitHub)
================================================================================

    powershell -ExecutionPolicy Bypass -File .\Mido-RDP-Install.ps1 -Mode Install


================================================================================
  ما سيحدث في كل الطرق
================================================================================

  المثبّت يتكفّل بـ: Python + Git ← المكتبات ← إنشاء .env ← تسجيل دخول تيليجرام
  ← التحقق من توكن البوت ← تأمين الصلاحيات ← فحص شامل.

  سيسألك الإعداد عن:
    APP_ID / API_HASH  ← من https://my.telegram.org
    رقم الهاتف         ← بصيغة دولية مثل +201234567890
    كود تيليجرام       ← يصلك في التطبيق
    كلمة مرور التحقق بخطوتين (إن كانت مفعّلة على حسابك)
    توكن البوت         ← من @BotFather في تيليجرام

  وفي النهاية سيسألك: "هل تريد تشغيل البوت الآن؟ (y/N)" → اكتب  y

  • لو عندك ملف جلسة من جهاز قديم (account.session) ضعه بجانب الملفات وشغّل:
    powershell -ExecutionPolicy Bypass -File .\Mido-RDP-Install.ps1 -Mode Setup -SessionFile .\account.session
    (يُتحقق من الجلسة باتصال حقيقي قبل اعتمادها، ولا يُحذف أي ملف جلسة أبدًا)


--------------------------------------------------------------------------------
التشغيل في أي وقت لاحق
--------------------------------------------------------------------------------
    اضغط مرتين على:   Mido-Start.cmd     (داخل مجلد المشروع %USERPROFILE%\Mido)
    أو:
    .\.venv\Scripts\python.exe -m zira

    (للتشغيل التلقائي عند بدء السيرفر: قسم Task Scheduler في deploy\WINDOWS-RDP.md)


--------------------------------------------------------------------------------
لو حصلت مشكلة
--------------------------------------------------------------------------------
    • سجل المثبّت (كل الأسرار مقنّعة داخله):   %TEMP%\mido-install.log
    • فحص شامل بدون أي تعديل:
      powershell -ExecutionPolicy Bypass -File .\Mido-RDP-Install.ps1 -Mode Check
    • إصلاح (لا يحذف أي جلسة أو قاعدة بيانات):
      powershell -ExecutionPolicy Bypass -File .\Mido-RDP-Install.ps1 -Mode Repair
